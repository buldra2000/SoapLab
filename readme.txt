# SoapLab

1 Configurazione database e avvio applicativo: 
    1.1 Importare su phpmyadmin il file sql/SoapLabDB.sql
    1.2 Modifica db.php credenziali se necessario
    1.3 Copiare cartella in C:/xampp/htdocs/
    1.4 Avviare i moduli Apache e MySQL da XAMPP Control Panel.
    1.5 Aprire il browser all'indirizzo: http://localhost/soaplab/index.php
